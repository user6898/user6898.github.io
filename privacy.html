Privacy Policy

Application: meowxology-auto  |  Last updated: November 10, 2026

1. Overview

meowxology-auto ("the Application") is a personal automation tool used exclusively by its owner to generate and publish videos to the owner's own TikTok account via the official TikTok Content Posting API. The Application has no public users and collects no data from any person other than the owner.

2. Data We Access

Through the TikTok Login Kit and Content Posting API, with the owner's explicit authorization, the Application accesses:

  • user.info.basic: basic profile information (open ID, display name, avatar) of the owner's own TikTok account, used only to confirm the target account for publishing;
  • video.upload / video.publish: permission to upload videos as drafts or publish videos to the owner's own TikTok account.

3. Data We Store

The Application stores only the minimum technical data required for publishing on the owner's own machine:

  • OAuth tokens (access token, refresh token) for the owner's own account, stored locally and never transmitted to any third party;
  • Publishing identifiers returned by the API (such as publish_id), used solely for tracking publishing status.

The Application does not collect, store, or process any data about TikTok users other than the owner. There are no analytics, no tracking, and no advertising identifiers.

4. Data Sharing

We do not sell, rent, share, or disclose any data to any third party. Data is exchanged only between the Application and TikTok's official API endpoints over HTTPS.

5. Data Retention and Deletion

  • Tokens and publishing records are retained locally only as long as needed for the Application's operation.
  • The owner may revoke the Application's access at any time via TikTok account settings, and may delete all locally stored data at any time.

6. Security

API credentials and tokens are stored locally in an environment file that is excluded from version control and never published.

7. Changes to This Policy

We may update this policy from time to time. The latest version is always available at this URL.

8. Contact

For questions about this policy, contact the owner via the TikTok account associated with the Application.
